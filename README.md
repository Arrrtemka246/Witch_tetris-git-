# W.I.T.C.H. Tetris — The Spell of Phobos

Тестовая сборка **v6.36.1** фанатской некоммерческой игры по вселенной «Чародеек» (W.I.T.C.H.). Проект сочетает классический тетрис, визуальную новеллу, сюжетные развилки, ломание четвёртой стены, секретные коды и отдельные мини-игры.

Игра предназначена для личного тестирования автором и ограниченным кругом знакомых. Все права на исходную вселенную и персонажей принадлежат их правообладателям.

## Быстрый запуск

Требуется Python 3.11+ и Pygame 2.6+.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 main.py
```

В Windows активация окружения выполняется командой:

```powershell
.venv\Scripts\activate
py -m pip install -r requirements.txt
py main.py
```

Скачать текущую тестовую ветку целиком можно через **Code → Download ZIP**, предварительно выбрав ветку `codex/v6.36.1-hotfix`.

## Сюжетные этапы

- 0–99 линий: Фобос контролирует превращённых персонажей.
- 100–199: сопротивление усиливается, запускается сюжетная кат-сцена.
- 200 линий: выбор победителя — Стражницы или Фобос.
- Ветка Стражниц: свободная игра с классическими блоками и отдельной музыкой.
- Ветка Фобоса: 80% шанс хоррор-фигур и 20% шанс обычных фигур без персонажей.
- 300 линий в ветке Фобоса: секретная комната с одним из двух случайных вариантов расположения Фобоса.

## Основное управление

- `←` / `→` или физические `A` / `D` — движение фигуры.
- `↓` или физическая `S` — мягкое падение.
- `↑` — мгновенное падение.
- физические `W`, `X` или `Z` — вращение независимо от раскладки клавиатуры.
- `C` или `Shift` — HOLD.
- `Space` / `Esc` — пауза.
- `M` — включить или выключить музыку.
- `Shift+Q` — добавить 10 линий для тестирования сюжета.
- `F11` или `Cmd/Alt+Enter` — полноэкранный режим.

У мини-игр собственные подсказки управления отображаются на экране.

## Что исправлено в v6.36.1

- Восстановлена музыка этапа 0–99; трек `Arrogant Prince of the Obsidian Court` больше не используется в ветке Фобоса после 200 линий.
- Для победной ветки Стражниц добавлен музыкальный fallback.
- Фоновая музыка полностью останавливается на время роликов кодов `MATRIX` и `PORN`.
- Исправлена фильтрация реплик после выбора победителя и исчезновения персонажей.
- `START SPEED` теперь действительно меняет скорость падения, не подменяя сюжетный счётчик линий.
- Очищены лишние фрагменты у вырезанных спрайтов; кат-сцена Фобоса использует 14 корректных кадров.
- В комнате Фобоса случайно выбирается стол или трибуна; они больше не накладываются друг на друга.
- В Collection оставлен один исходный вид каждой хоррор-фигуры и убраны лишние повороты/кадры.
- Переработаны границы и логика Will Maze, достижимость целей Heart Breaker и Taranee Fire Shot, приседание Caleb Runner и механика Cornelia Earth Garden.
- В Hay Lin Flight препятствия изображаются облаками тёмной магии; луч Irma Whirlpool стал уже.
- Курсор мыши скрывается внутри мини-игр и возвращается после выхода.

Полный журнал находится в [`V6_36_1_CHANGES.md`](V6_36_1_CHANGES.md).

## Известные отложенные вопросы

По решению автора в этой версии **не исправляются**:

- управление фигурой во время анимации удаления линий;
- конфликт клавиши `X` в Phobos Tetris.
